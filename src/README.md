# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share any activity on Facebook, X, or WhatsApp, or copy its direct link
  without logging in. Shared links highlight the activity on arrival. If clipboard
  access is unavailable, select and copy the displayed link manually.
